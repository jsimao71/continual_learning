# Controlled cumulative-Jacobian results

The one-block linearization is informative (mean cosine 0.782), but fidelity falls with composition: cosine declines to 0.552 over two blocks and 0.335 over four, while relative error rises from 0.624 to 1.047. Piecewise re-linearization remains appreciably better than the frozen cumulative path at longer horizons. The controlled result therefore supports local state-dependent linear propagation, but rejects a globally accurate four-block linear surrogate. Signal directions accumulate error faster than behaviorally stable nuisance directions.
