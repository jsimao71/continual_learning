\title{Toward a Theory of Computation for Learned Transformer Machines:\\Tasks, Resources, Learnability, Composition, and Closure}

\begin{abstract}
Classical expressivity asks what an idealized Transformer can compute; benchmark studies ask whether a trained model succeeds. Between them lies the theory of a \emph{learned} Transformer machine. We formalize task structure, information sufficiency, machine resources, acquisition probability, one-pass and autoregressive composition, and resource-scheduled closure. The operational object is compound, $\mathcal M=(F_\theta,C,S,I,\mathbb T,\mathcal B)$. Five executable fixed-weight witnesses calibrate representability under explicit finite encodings. Their contrast with Paper 0.85---where trained one-token and autoregressive machines share frontier $K=3$ and fail at unseen $K=4$---makes the central distinction concrete: representability is not reliable acquisition. Empirical papers appear only as late, nonessential anchors.
\end{abstract}

\section{Introduction}
A fixed architecture may represent a computation that training rarely discovers; a trained model may fit bounded instances without a reusable rule; a reusable local rule may still fail under composition or termination. Autoregression changes the effective machine by applying the same transition repeatedly. We therefore separate
\[
\boxed{\text{representability}\ne\text{learnability}\ne\text{reliable acquisition}\ne\text{systematic executability}\ne\text{closure}.}
\]
The evidential layers are distinct: propositions follow from premises; executable hand-weighted constructions establish finite-domain representability; trained-model experiments measure acquisition; conjectures remain prospective.

\section{Task families and concrete examples}
A task family is $\mathcal T=(\mathcal X,\mathcal Y,\mathcal D,\mathcal R)$, where $\mathcal D$ is a generator/distribution and $\mathcal R$ the declared prior. Its partially ordered complexity vector is
\[
\mathbf c=(s_{\rm atom},k_{\rm comp},b_{\rm branch},v_{\rm state},n_{\rm nuisance},m_{\rm context},\ldots).
\]
The coordinates measure atomic syntax, composition/proof depth, branching, state, nuisance, and context/memory demand. Raw length need not increase composition depth.

\subsection{From concrete tasks to the abstract task vector}
\paragraph{T1: atomic mapping.} \texttt{A->B, B->C, QUERY B} targets \texttt{C}: very low syntax, $k=1$, unit branching, negligible state/nuisance.
\paragraph{T2: contextual lookup.} \texttt{A->X, B->Y, C->Z, QUERY B} targets \texttt{Y}: low syntax and $k=1$, but contextual cross-token transport. Distractors can increase length without depth.
\paragraph{T3: grandparent.} \texttt{PARENT C B, PARENT B A, QUERY GRANDPARENT C} targets \texttt{A}: parent lookup composed twice.
\paragraph{T4: root.} For \texttt{C->B->A->R}, a one-token answer needs bounded internal composition; multi-token \texttt{C B A R} needs recurrence and termination for scalable execution.
\paragraph{T5: ancestor-(k).} \texttt{ANCESTOR C 2} needs node-and-counter state, decrement, and termination.
\paragraph{T6: proof chain.} From \texttt{A}, \texttt{A->B->C->D}, decide \texttt{D?}; proof depth, distractors, and branching vary independently.
\paragraph{T7: unification.} \texttt{P(f(x),y)} with \texttt{P(f(a),b)} yields $\{x=a,y=b\}$: high syntax, binding state, and functor depth.
\paragraph{T8: branching search.} \texttt{A->B,A->C,B->D,C->E,...} separates search width and frontier/visited state from proof depth.

\section{Information sufficiency}
For query $X$, context $D$, target $Y$, and prior $\mathcal R$, validate
\[
I(Y;D\mid X)=H(Y\mid X)-H(Y\mid X,D),\qquad H(Y\mid X,D,\mathcal R)=0
\]
for deterministic identifiable tasks. Record
\[
\mathcal I=(H(Y\mid X),H(Y\mid X,D),I(Y;D\mid X),\mathcal R,A_{\rm Bayes},|\mathcal H_{X,D,\mathcal R}|,m_{\rm id}).
\]
These mean, respectively: query-only uncertainty; remaining uncertainty after context; context's added information; declared hypothesis family; best possible expected accuracy; number of consistent hypotheses; and minimum context for identification.

\paragraph{Impossible random mapping.} \texttt{A->7, B->2, QUERY C} is underdetermined if $C$'s output is independent: $H(Y\mid X,D)>0$.
\paragraph{Permutation completion.} \texttt{A->3, B->1, C->4, QUERY D} forces \texttt{D->2} only under the prior that outputs permute $\{1,2,3,4\}$. This is constraint completion, not general induction.
\paragraph{Affine induction.} Under $f(x)=ax+b\pmod7$, $f(0)=3,f(1)=5$ give $b=3,a=2$. The prior changes identifiability.
\paragraph{Standard Bayes-risk fact.} Positive conditional entropy on positive measure implies $A_{\rm Bayes}=\mathbb E\max_yP(Y=y\mid X,D,\mathcal R)<1$. This routine fact enforces dataset discipline; it is not a novelty claim.

\section{Machine, controller, and resource formalism}
$C_0$ invokes $F_\theta$ once; $C_1$ invokes it autoregressively; $C_2$ gives state typed fields; $C_3$ is an external action/tool loop.
\begin{definition}[Compound learned machine]
\[
\mathcal M=(F_\theta,C,S,I,\mathbb T,\mathcal B),qquad
P_{\rm acquire}=P_\Pi[A(\tau,\mathbf c;\mathcal M,\Pi)\ge\gamma].
\]
$F_\theta$ is the learned transition map, $C$ its scheduling protocol, $S$ writable state, $I:q\mapsto D$ information, $\mathbb T$ partial external operations, and $\mathcal B$ context/call/token/time/memory budget.
\end{definition}
Report $\Delta\mathcal M=(\Delta C,\Delta S,\Delta I,\Delta\mathbb T,\Delta\mathcal B,\Delta\Pi)$, so easier prompts, stronger tools, more time, and different training are not all ``augmentation.''

\section{Six computational axes}
\begin{enumerate}
\item \textbf{Atomic acquisition:} which local operators pass across seeds?
\item \textbf{One-pass composition:} $K_{\rm internal}=\max\{K:A(f^K)\ge\gamma\}$, controlling dependency radius, depth, nuisance, and length.
\item \textbf{Autoregressive composition:} $s_{t+1}=F_\theta(X,s_{\le t})$; report transitions, stopping, sequence success, and train-short/test-long behavior.
\item \textbf{Closure signature:} separate a contiguous tested frontier from a uniform resource-scheduled procedure.
\item \textbf{In-context information:} separate copying, completion, task selection, parameter estimation, and procedure induction.
\item \textbf{Tool/harness augmentation:} separate computational, acquisition, reliability, and efficiency gains.
\end{enumerate}
Much classical circuit/logical work studies a fixed one-pass Transformer under precision assumptions. It cannot be transferred automatically to $C_1$, where emitted tokens create serial applications of the transition map.

\section{Constructive witnesses and the learnability gap}
Representability asks whether $\exists W^*$ such that $\mathcal M(W^*)$ implements $\tau$; acquisition asks for $P_\Pi[\mathcal M(W_\Pi)\text{ passes }\tau]$. The hand-weighted witnesses instantiate the first statement without training.

\section{Composition and resource-scheduled closure}
For legal set $R_K$, per-$K$ solvability $\forall K\exists(\mathcal M_K,\mathcal B_K)$ differs from
\[
\exists\mathcal M\exists\mathcal B(K)\forall K<\infty:\ \mathcal M\text{ solves all }x\in R_K\text{ within }\mathcal B(K).
\]
Empirically, $K_{\rm prefix}$ is the largest $k$ for which every tested $1\le j\le k$ passes. Report
\[
\Sigma=(K_{\rm train},K_{\rm test},K_{\rm prefix},\rho_{\rm step},\rho_{\rm stop},g,f_{\rm fail}).
\]
\begin{proposition}[Finite observations do not establish closure]
For any finite evaluated input--output set consistent with a resource-scheduled procedure, a finite lookup machine agrees on all observations and diverges on an unobserved legal input.
\end{proposition}
\begin{proposition}[Budgeted local composition]
If $D$ is closed under deterministic $T:D\to D$, and $C$ exactly preserves state, invokes/integrates $T$, and applies a total correct stop rule, then $T^k(x)$ is representable whenever all states and trace fit $\mathcal B$.
\end{proposition}
Independent reliability $r_{\rm stop}\prod_i r_i$ is only a baseline; acquisition and reliability are separate.

\section{Information interfaces and tool algebra}
Retrieval changes evidence: $q\mapsto I(q)=D\mapsto F_\theta(q,D)$. Tools are semantic: $T_0$ lookup, $T_1$ local transition, $T_2$ transform, $T_3$ search/closure, $T_4$ programmable executor.
\begin{table}[H]\centering\scriptsize\sloppy
\begin{tabularx}{\linewidth}{lYYYY}\toprule&$C_0$&$C_1$&$C_2$&$C_3$\\\midrule No tool&one-shot&generation&typed scratchpad&environment loop\\ $T_0$&evidence&retrieve/generate&evidence state&iterative retrieval\\ $T_1$&one call&serialized calls&current/counter&parent iteration\\ $T_2$&delegated transform&calculator/PAL&expression/result&CAS/SQL\\ $T_3$&delegated answer&closure call&query/result&search\\ $T_4$&run code&generate/execute&program state&code agent\\\bottomrule\end{tabularx}
\caption{Controller $\times$ tool configurations, not an intelligence ladder.}\end{table}
For information $I_s$, acquisition $Q$, and execution $E$, $P(I_s\cap Q\cap E)=P(I_s)P(Q\mid I_s)P(E\mid Q,I_s)$. This equals endpoint success only when shortcut branches are excluded. The heterogeneous-network extension is developed separately in Paper 0.2.

\paragraph{Fixed one-pass.} Results depend on attention, precision, positions, and uniformity \cite{hahn2020,hao2022,merrill2022,merrill2023parallel,merrill2023logic,chiang2023,strobl2024}; universality is representability, not acquisition \cite{yun2020,perez2021}.
\paragraph{Autoregressive/CoT.} Serial tokens change expressivity under explicit assumptions \cite{merrill2024cot,li2024,joshi2025,bavandpour2025}.
\paragraph{Mechanistic circuits.} Residual decomposition, induction heads, and causal tracing distinguish description from necessity \cite{elhage2021,olsson2022,meng2022}.
\paragraph{Composition limits.} Endpoint success can conceal brittle, distribution-specific computation \cite{dziri2023,huang2025}.

\section{Discussion and conclusion}
Validate identifiability; establish local competence; measure contiguous composition and recurrence frontiers; only then interpret mechanism. Fixed weights calibrate representability, while learned experiments measure acquisition. Resource-scheduled closure is a quantified property of one reusable procedure, not a long successful trace.
