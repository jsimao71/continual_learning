# S1 deep predicates

No predicate passes the three-seed depth-general competence gate. Parent, grandparent, ancestor_k, and root fail even shallow held-out competence. isAncestor is the strongest result but is seed/model-depth unstable, so it is a mixed local success rather than evidence for a learned depth-general relation. L_min(d) is not estimable; the supported outcome class is threshold failure.
