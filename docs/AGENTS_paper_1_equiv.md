# AGENTS.md — Paper 1 Revisit: Functional Equivalence and the Gate to Continual Structural Learning

## Mission
Preserve Paper 1's completed controlled weak-bridge positive result and frozen-Qwen observational null. Persistent consolidation remains blocked until natural candidate-level causal utility or a matched-budget quality/materialization frontier shift is demonstrated.

Revisit the continual-learning plan using the stronger equivalence-class hypothesis from Papers 0.5/0.6. The learning target is not a recurrent attention motif. It is a validated functional/relational equivalence class after nuisance variation is factored out.

## Consolidation principle
Conceptually group transient observations by an empirically validated equivalence relation:

{o_1,...,o_n} / ~  -> persistent prototype/controller/rule candidate

This is conceptual quotienting, not a claim of an exact quotient space.

Consolidate only when common structure:
1. recurs across identity-disjoint examples;
2. predicts marginal utility beyond base/surface controls;
3. survives matched causal intervention;
4. transfers across nuisance transformations;
5. preserves exceptions/override;
6. improves matched-budget future outcomes.

## Evidence ontology
Keep four levels explicit:
- representation/observation;
- prediction;
- intervention/function;
- consolidation.

Also distinguish representational, dynamical, functional, and structural-role invariance. Do not promote evidence silently between levels.

## H1 — Functional role beats raw recurrence
Test whether role features predict causal utility better than magnitude/similarity:
- bridge role;
- predictive-equivalence membership from 0.5;
- semantic/type equivalence from 0.6;
- path/connectivity role;
- residual common-subspace membership;
- task-conditioned requested resolution.

Baselines include attention magnitude, motif stability, retrieval score, lexical/semantic controls, frequency, and generic layer features.

## H2 — Importance is not magnitude
Generalize the weak-bridge finding. Low-score candidates can have high marginal utility because of relational position.

Natural targets must include candidate removal utility, answer-likelihood delta, generated-answer quality delta where reliable, and path/evidence completion only as a diagnostic.

## H3 — Immediate natural candidate-level gate
Before any learner, regenerate frozen-model candidate-level features for HotpotQA and QASPER (or repository-approved replacements). Perform actual native K/V materialization, identity-disjoint validation/test splits, and equal token/byte budgets.

Compare:
- base score;
- lexical/semantic surface controls;
- graph structure;
- 0.5 predictive-equivalence features where applicable;
- 0.6 semantic/type-equivalence features where applicable;
- combined functional-role features.

Success requires a paired frontier improvement and/or incremental held-out causal-utility prediction on both task families. A second well-powered natural causal null should trigger the existing stop rule, not a more flexible learner.

## H4 — Superposition as common-role extraction
Use 0.5/0.6 results to test whether repeated residual computation exposes common task-relevant subspaces despite variable raw attention patterns.

Candidate frozen features: common residual direction/subspace, equivalence-class prototype, relational-role embedding, bridge/path role, uncertainty/confidence, and exception/override indicators.

Test them first as frozen selectors. No persistent updates before the natural gate.

## H5 — Consolidation target after the gate
If and only if the natural gate passes, compare matched-capacity persistent mechanisms:
1. count/statistics memory;
2. prototype/local-rule memory;
3. hidden-state-conditioned prototype;
4. structural/functional-equivalence prototype;
5. low-rank adapter/fast-weight baseline;
6. shuffled/random structural controls.

Primary question: does equivalence-aware consolidation outperform ordinary content/hidden-state adaptation under the same memory/update budget?

## H6 — Preserve exceptions
A learned invariant must not erase context-sensitive exceptions. Explicitly test Paper 0.5-style override and Paper 0.6 fine-vs-coarse resolution after consolidation.

Measure learned-case gain, unrelated-case harm, override preservation, calibration, forgetting, contamination, reversibility, and provenance.

## H7 — Toward relational rules
Do not jump directly from graph prototypes to symbolic rules. Require a progression:
predictive equivalence -> semantic/type equivalence -> relational-role equivalence P(x,y) -> variable-renaming invariant P(X,Y) -> compositional rule P(X,Y)&Q(Y,Z)=>R(X,Z).

This likely motivates a separate relational-invariance/ESR bridge paper. Paper 1 should export schemas and evidence gates, not claim symbolic rule discovery.

## Revised decision tree
A. Natural candidate causal gate fails -> stop/defer consolidation.
B. Gate passes but equivalence-aware features add nothing -> use simpler structural/base control.
C. Equivalence-aware frozen control helps -> test persistent prototypes.
D. Persistence helps but breaks overrides -> reject/modify consolidation rule.
E. Persistence transfers with low harm -> proceed to structural adapters and longer-horizon continual learning.

## Required outputs
Natural matched-budget frontier; candidate removal utility; incremental prediction by feature family; invariant-type ablation; weak-bridge analysis; override-preservation table; if gate passes, matched-budget consolidation comparison and rollback/provenance audit.

## Guardrails
Do not equate recurrence with learnability, geometry with utility, attention weight with importance, synthetic mechanism sufficiency with natural generalization, or persistent performance gain with symbolic rule induction.

## Definition of done
Paper 1 revisit is complete when the natural candidate-level gate is run with actual materialization; 0.5/0.6 equivalence features are evaluated as frozen controls where applicable; a stop/go decision is recorded; persistent learning is attempted only after a pass; exceptions and provenance are first-class evaluation criteria.
