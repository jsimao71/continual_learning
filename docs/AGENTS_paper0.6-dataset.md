# PART I — S1 TAXONOMIC LOOKUP

## Goal

First make the model reliably learn a known hierarchy.

Use explicit balanced trees:

```text
root
  category
    subcategory
      instances
```

Suggested scales:

```text
branching_factor = [2,4,8]
tree_depth = [2,3,4]
instances_per_leaf_group = [8,16,32]
```

Use both:

```text
natural_labels
arbitrary_labels
```

Queries:

```text
parent(instance) -> parent
ancestor_k(instance) -> ancestor
root(instance) -> root
```

Use 3–5 templates per query.

### Holdouts

Hold out:

```text
leaf identities
template variants
selected branches where feasible
```

### Competence gate

Preferred:

```text
>= 0.80 held-out accuracy
```

No semantic mechanism claims below gate.

### Required metrics

At every layer:

```text
target_probability
target_rank
target_margin
top1_correct
first_top1_layer
stable_top1_layer
settling_delay
output_entropy
within_class_JS
between_class_JS
hierarchy_RSA
nearest_parent_recovery
cross_template_invariance
residual_covariance_trace
effective_rank
```

Order parameters:

\[
S_{\ell,k}=E[m_{\ell,k}]
\]

\[
N_{\ell,k}^2=Var(m_{\ell,k})
\]

\[
\Gamma_{\ell,k}
=
S_{\ell,k}/\sqrt{N_{\ell,k}^2+\epsilon}
\]

and class organization:

\[
R_{\ell,k}
=
D_{between}/(D_{within}+\epsilon).
\]

# PART II — S2 RELATIONAL CATEGORY LEARNING

## Goal

Move beyond entity-token lookup.

Generate arbitrary entities with reusable relation structure.

Example facts:

```text
has_feature(x, a)
located_in(x, b)
acts_like(x, c)
connected_to(x, d)
```

Category is generated by a known rule:

```text
C = f(relations)
```

Examples:

```text
C1 iff has_feature=A AND located_in=B
C2 iff acts_like=C OR connected_to=D
```

Balance category frequencies.

### Holdouts

Hold out:

```text
entity identity
relation combinations
templates
```

The model must generalize category membership to unseen entities.

### No-shortcut checks

Estimate:

```text
I(entity_token; target)
I(single_relation; target)
I(proper_relation_subset; target)
I(full_relation_set; target)
```

Fail dataset validation if an entity token or unintended singleton relation predicts the target.

### Required causal tests

Compare donors:

```text
same entity / different template
same category / different entity
same parent / different subcategory
unrelated same-target
cross-category
permuted-category control
```

Measure:

```text
JS damage
target-margin damage
top1 flip rate
block-update similarity
SA-update similarity
FF-update similarity
head-utility overlap
```

# PART III — S3 COMPOSITIONAL SEMANTIC ABSTRACTION

## Goal

Generate semantic classes from attributes rather than stored leaf mappings.

Each instance:

```text
x = (a1, a2, ..., am)
```

Possible attributes:

```text
shape
color
motion
texture
size
relation
```

Define nested categories with explicit rules.

Example:

```text
level1: shape
level2: shape + motion
level3: shape + motion + relation
```

Use balanced functions.

### Holdout

Test on unseen attribute combinations.

### Predictive semantic order

Define:

```text
minimum_sufficient_attribute_subset
```

or exact conditional entropy criterion.

Test whether semantic decision depth correlates with predictive semantic order more than raw sequence length.

### Required metrics

For each abstraction level:

```text
first_top1_layer
stable_top1_layer
margin_SNR
hierarchy_RSA
within_between_ratio
causal donor hierarchy
head recruitment
```

## SA vs FF


```text

```

Do not assume SA/FF roles.

## Heads

Per head:

```text
zero ablation
mean replacement
same-category replacement
cross-category replacement
```

Compute:

```text
semantic stability utility
hierarchy discrimination utility
utility correlation across abstraction levels
top-k overlap
new-head recruitment by semantic level
```

## Abstraction-depth analysis

For every requested level k:

```text
L_first(k)
L_stable(k)
```

Test whether coarser levels emerge later, earlier, or concurrently.

No monotonic ladder assumption.

## Semantic replacement hierarchy

Required donor ordering:

```text
same-instance template variant
same category
sibling category
same-target unrelated
cross-category
permuted control
```

The strongest positive result would show causal damage increasing with semantic distance.

Only after controlled semantic competence succeeds.

# FALSIFICATION CRITERIA

The program is weakened if:

- S1 cannot reach competence despite reasonable capacity/training;
- same-category causal replacement is no better than cross-category;
- hierarchy RSA is not above permuted controls after competence;
- held-out entities fail in S2;
- unseen attribute combinations fail in S3;
- semantic decision depth shows no structure after controls;
- natural-label effects vanish in arbitrary-label trees;
- pretrained effects disappear under residual-proximity matching.

# FINAL SCIENTIFIC TARGET

The strongest successful result would be:

\[
\boxed{
\text{A Transformer trained on an exact synthetic ontology learns nested,
behaviorally usable semantic equivalence classes whose residual updates and
causal substitutions partially reuse structure across members and abstraction
levels, and whose dynamics generalize from taxonomy lookup to relational and
compositional semantics.}
}
\]

A strong negative result is also publishable:

\[
\boxed{
\text{If geometry appears before competence and fails to survive relational
or compositional generalization, semantic-looking structure is not sufficient
evidence of learned abstraction.}
}
